# Disposable packet selector and aggregate guards

This is an isolated protocol candidate, with no CLI execution route, application
hook, production enablement or new native inference permission. Its marker is
`disposable-whole-passage-selector-v1`. The previous offline W-ID planner stays
unchanged. Its five availability gaps and unmeasured relevance, abstention and
legal quality remain open; selecting all mock IDs is no evidence of those goals.

## Boundary and accounting declared before evaluation

An operator supplies a trusted authorization function. It must independently
resolve the descriptor's question, full inventory and plan hashes to an acquired,
authorized matter context and exact document versions, and check current access.
The adapter itself does not implement production permissions. Passing a lambda
that returns true is appropriate only for the invented mock fixtures. Caller
hashes, source labels and frozen plans do not establish authorization or blob
integrity. This boundary is in-process; arbitrary Python mutation of its private
internals or replacement of the authorizer is outside the trust model.

The selector serializes, validates and rebuilds the entire inventory after copying,
including unused evidence, then executes only that snapshot. Both caller context
and local provider settings are checked around authorization and before/after
transport. Authorization changes during a request discard its result. No original
is overwritten and no review decision is inferred. Returned selections remain
separate full passages with exact offsets, text hashes and source version pins;
a whole passage does not establish whole-document completeness.

The per-request profile independently rejects noninteger, boolean, nonpositive or
above-8192 limits; provider configuration must exactly match. An undersized blocked
envelope fails before transport. Existing eight-passages/4000-copied-byte and
conservative UTF-8-plus-reserves accounting stay in force. Provider `_complete`
retains its local routing, authentication, model, deadline and response checks;
completion is capped at 1000 tokens, raw response at 8192 bytes, parsed selection
at 4096 bytes. Unknown, cross-packet, legacy, repeated and translated IDs fail.
No retry, fallback, sentence repair or generated synthesis is introduced.

An explicit allowance must fit the **entire** plan before any call, independently
for completion attempts, conservative units and copied text bytes. Maximums are
eight attempts, 65536 units and 32000 bytes. Reservation is locked, one-shot per
packet and checked again against cumulative spend. Reserved attempts consume their
full conservative cost even on failure, cancellation, revocation or invalid output;
there is no refund or automatic retry. Metadata GETs are separate from completion
attempts. Neither reserved units nor copied bytes are measured tokens or billing.
The ledger lasts for one in-memory session; it is not crash-safe or cross-process
and reconstructing a session would create a new allowance. Native execution needs
a durable, one-use campaign authority before this can become a runtime feature.

## Frozen qualification rules

Freeze candidate, invented P1601–P1606 fixtures, evaluator, this declaration and
contracts before the first evaluation. Retain the first complete report and file
hashes; do not tune candidates or fixtures after observing results. Require all
exact copies, unchanged caller data, exact reserved totals and no real network,
inference, private documents, persistence or review changes. Fixed mock responses
use only nominated IDs, never legal labels. Test concurrency as protocol behavior
only, including duplicate reservations and five independent in-flight packets.

Falsification contracts cover each allowance dimension, hard caps, blocked/no-source
plans, changed unused sources and wires, invalid hashes, trusted-authorizer denial,
revocation and mutation races, provider changes, invalid/cross-packet selection,
502/metadata/model failure, consumed cancellation/failure, no retries and exact
transport bounds. Reproduce the entire fixed synthetic report in read-only Linux
with networking disabled and no runtime/provider/private mounts. Keep existing CI
jobs, worker counts, time limits, coverage and five timing reserves intact.

A later native acceptance trial needs fresh cases, separate executable permission,
aggregate campaign accounting, exact local model/transport identity and retained
attempt receipts. The older eleven-call declaration cannot authorize this recipe.
Historical HTTP 502 root cause, sustained five-job model capacity, legal quality,
reviewed corpus and the owner's focused-analysis v3 decision remain pending.
