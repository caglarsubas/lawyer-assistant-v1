# Whole-passage inventory packet experiment

Declare and freeze this offline candidate before grading P1501–P1516. Keep the
previous frozen native acceptance declaration, source suites, implementation and
first preflight unchanged. No private matter, setting, credential, inference,
source acquisition, application hook or review decision is an experiment input.

## Candidate and bounds

`offline-whole-passage-packets-v1` copies original passages whole, including
leading/trailing spaces, blank separators, CRLF and complete long lines. It never
clips or joins passages to make a condition appear complete. Whole passages are
not whole documents; every candidate explicitly carries document-completeness
uncertainty. Separate passages and versions have no inferred semantic link.

Nominate all nonblank eligible passages as inventory candidates, not relevance
results. Rank lexical query overlap within each exact document version and take
source versions in round-robin order before revisiting them. Place candidates by
bounded first fit into existing packets before adding a new packet. Stable `W…`
bundle IDs are global within the declared inventory; each `P…` packet admits only
its own IDs. Keep complete source identity and all omissions outside model context.
The exact packet messages contain no expected groups or evaluator labels.

Keep the existing per-envelope limits: at most 8192 conservative accounting
units, 4000 copied UTF-8 bytes and eight original passages. Count the complete
serialized message bytes plus 256 framing and 1200 completion-reserve units;
these are not measured tokenizer counts. A later selector would request at most
1000 completion tokens per packet. No provider client or adapter is implemented
or activated in this experiment.

Permit at most eight packets per question: ceilings of 65536 context-accounting
units, 32000 copied bytes and eight potential future completion requests. Report
actual packet/copy/reserve totals and full omissions. This changes aggregate cost;
it does not enlarge a single request or make additional work free. Retain the
2000-passage, two-million-code-point and 20000-nonblank-line scan bounds. Reject
unknown metadata fields before serialization, ambiguous revisions and forged
hashes. Retain overlong passages, insufficient envelopes, packet caps, empty text
and unrepresented sources as explicit gaps rather than trimming or silently
discarding them from denominators.

Each plan seals the full original inventory, question, budgets, all exact wire
messages, packet membership and omissions. Resolution rebuilds everything and
rejects stale unused passages, changed questions/caps/wires, duplicate/unknown or
cross-packet IDs. Empty selections remain unqualified. Whole selected text and
version aliases are copied separately without synthesis. This seal is research
metadata, not matter authorization, native execution authority or source rights.

## Fresh frozen comparison

Freeze fresh invented text, revisions, questions, expected complete groups,
implementation and evaluator before their first grade. These labels are authored
for engineering and have no independent legal adjudication. Never send labels to
the planner or model. Do not replay the exposed P1401–P1414 set to tune a success.

Run three offline preparations on the same new cases: the unchanged v2
single-envelope planner, the whole-passage candidate with one packet, and the same
candidate with up to eight packets. The latter pair changes packet capacity only;
require byte-identical first packets. Comparison with v2 also changes nomination,
atomization and total budget, so it is not a causal accuracy experiment.

Grade a required group available only when every expected fragment from its exact
document revision occurs in one atomic bundle. Co-presence in separate passages
or packets does not establish a complete condition. Preserve supportive/adverse
groups, late evidence, source-volume and depth pressure, overlong/blocked cases,
empty inventories and missing information. Report every group in the full
denominator, candidate gaps, packet counts, aggregate cost and version coverage.
An irrelevant inventory candidate is not relevance or abstention. Negative-case
accuracy, model selection, instruction resistance and legal quality remain
unmeasured. Exact-copy resolution tests establish protocol integrity only.
