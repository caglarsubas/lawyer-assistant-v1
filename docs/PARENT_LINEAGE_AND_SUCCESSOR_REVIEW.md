# Guarded parent-lineage navigation and separate successor review

After [read-only renewal reconciliation](RENEWAL_RECONCILIATION_LINEAGE.md), a
verified link with complete admissions offers three explicit follow-ups: the exact
captured historical parent, ordinary successor identity navigation, or separate
successor independent-review preparation. Arrival and navigation do not load
passages, review notes, review inputs, exports, inference or rich workspace content.

## Captured parent and current head remain distinct

Each follow-up re-observes the original actor-bound receipt/link/admissions before
and after its exact authorized target lookup. Partial results are not presented.
Changed linkage, admission, access, filters, session or expiry retires the reply and
clears all prepared links. These separate reads are not an atomic permission lease.

Parent navigation pins the frozen parent context/version/manifest and, when a
review was captured, its exact event ID and authenticated packet hash. The target
lookup uses a bounded one-record historical metadata window; it does not scan a
list or substitute today's head. A subsequent head remains separately observed and
does not rewrite the captured event or establish reversal, ancestry or legal effect.
When no review was captured, the link selects the original context without
inventing a historical decision, even if that context now has a review head.

The destination gets a distinct session-only return intent with the same customer
OR, workspace date field/range, separate source-record dates and review bucket.
Fresh comparison baselines belong to this explicit new selection; the original
selection, baselines, evidence versions and stored history remain unchanged. The
destination rechecks the frozen context and historical packet before tools. A lost,
expired or substituted token closes the view without fallback. No public graph or
browser persistence is added.

## Focused independent review

The successor can enter `prepare=review` only through a complete scoped return
intent with frozen context/version/hash and no selected historical review. Duplicate,
mixed and malformed routes close. An authorized lawyer can also explicitly select
the same context in their own portfolio and prepare a new independent review.
Tokens are principal-scoped and cannot be transferred to another lawyer's session.

The focused page initially displays intent only. Explicit preparation restores the
exact filters; explicit observation verifies the frozen version against the current
analysis, complete admissions and known review-head metadata. Opening review tools
is separate from fetching review content. Only a further explicit content action
invokes the original source/retained-grant, private-basis and independent-actor
guards. The author/source selector remains ineligible; customer tags and an
administrator role do not replace explicit matter content access.

Only new-review controls are available in this view. Research, renewal, historical
inspection and export remain separate workflows. Roles, observations, reasoning
and renewal assessment start blank; earlier lawyer decisions are not copied. The
current head is an expected-write identity, not inherited approval. Checks before
and after content reads prevent a changed head/version from leaving a stale form.

After a successful write, the exact submitted input and source view are checked,
then fresh authorized historical metadata must match the new event ID, packet hash,
decision, complete admission and the head observed before submission as predecessor.
The analysis revision/current version must still match. Only then is the new record
confirmed. Protected forms and source bodies are cleared after the write.

A pending, lost, truncated, gateway or otherwise uncertain write result closes the
form and offers fresh metadata observation. There is no automatic or manual POST
replay in the focused view, admission repair or claim that a newly observed head
proves the outcome of an uncertain request. Old and new events remain immutable.
Source permission, legal applicability, professional independence and legal
readiness are not granted by a matching identity or a recorded conditional review.
